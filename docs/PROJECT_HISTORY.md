# Project history

Sokratis-OS is not a new idea invented for an application. It grew as a
long-running private project with real iteration before this public-edition
candidate was prepared.

The original project contains domains that are not suitable for publication,
including personal material, private operational state, and strategic
implementation details. Its source history therefore remains private.

This public edition preserves the reusable control-plane concept and records
its lineage openly:

- it is a sanitized extraction from the Sokratis-OS project;
- it starts from a clean publication snapshot;
- it does not copy sensitive history or claim public activity that did not happen;
- future public changes will be recorded normally through issues, pull
  requests, tests, and releases.

The clean snapshot is a safety boundary, not an attempt to hide the project's
origin.
