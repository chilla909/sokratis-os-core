# Contributing

Thank you for helping improve Sokratis-OS.

## Before opening an issue

- Search existing issues and pull requests.
- Describe the problem and the smallest useful outcome.
- Do not include secrets, personal data, private prompts, or proprietary
  operational details.

## Before opening a pull request

- Keep the change focused.
- Add or update tests when behavior changes.
- Update documentation when the public contract changes.
- Run pytest locally.
- Explain limitations and verification evidence in the pull request.

Maintainers may ask for a smaller change or additional evidence. Please be
constructive and assume good intent.
